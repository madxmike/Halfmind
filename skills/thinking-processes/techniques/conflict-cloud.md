# Conflict Cloud

## Use When

- Two wants collide.
- The user states a dilemma: "we need X, but we also need Y".

## Technique

Write five boxes:

- A: the objective.
- B and C: the two needs.
- D and D': the two wants in conflict.

Read the cloud as: "in order to A, we need B. In order to B, we need D."
List the assumptions under each arrow.
Test each assumption with the user.
Find an injection that breaks one assumption.
The injection dissolves the conflict. A compromise does not.

Check:

- D and D' cannot coexist under the current assumptions.
- The injection breaks an assumption, not the objective.

## Failure Mode

The agent splits the difference. Both needs lose.

Source: Goldratt, "It's Not Luck", 1994 (evaporating cloud).
