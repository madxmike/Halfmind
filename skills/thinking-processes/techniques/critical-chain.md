# Critical Chain

## Use When

- The agent builds the plan.
- The plan has one scarce resource.

## Technique

Use the estimate with 50 percent confidence.
Move the safety from the tasks into one project buffer.
Name the constraint resource. The constraint resource sets the pace.
Sequence the tasks around the constraint resource.
Add a feeding buffer where a side path joins the critical chain.
State the buffer size as a number of days.

Check:

- One buffer covers the project.
- The constraint resource is named.
- The critical chain is the longest path with the constraint.

## Failure Mode

Each task hides its own safety. The project overruns the schedule.

Source: Goldratt, "Critical Chain", 1997.
