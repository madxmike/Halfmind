# Future Reality

## Use When

- The agent validates the design against the goals.
- The user asks "does this solution work?"

## Technique

Start from the injection.
Connect the injection to each desired effect with if-then logic.
Read the chain aloud and test each link.
Add an intermediate effect when a link does not hold.
Look for negative branches on each new link.
Look for a positive loop: a desired effect that strengthens the injection.

Check:

- Each goal has a logic path from the injection.
- No new undesirable effect appears without a treatment.

## Failure Mode

The agent asserts the result without the chain. The reader does not believe the design.

Source: Goldratt, "It's Not Luck", 1994 (future reality tree).
