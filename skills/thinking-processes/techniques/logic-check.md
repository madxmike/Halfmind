# Logic Check

## Use When

- The agent tests a claim or an arrow.
- A sentence claims a cause, a need, or a proof.

## Technique

Name the claim type:

- Necessity: "in order to A, we need B."
- Sufficiency: "if A and B, then C."

Test necessity: remove B. Does A fail?
Test sufficiency: add A and B. Does C always follow?
Find the missing cause when C does not follow.
Name the assumption behind each arrow.
Reject a tautology: the claim repeats its cause.

Check:

- The doc does not treat a necessary condition as a sufficient cause.
- Each arrow carries an assumption or an accepted fact.

## Failure Mode

The agent accepts a weak link. The design rests on a broken assumption.

Sources:

- Goldratt, "It's Not Luck", 1994 (logic trees).
- Dettmer, "The Logical Thinking Process", 2007.
