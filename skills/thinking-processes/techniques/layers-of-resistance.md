# Layers of Resistance

## Use When

- The agent orders the interview.
- The user resists the design or the problem.

## Technique

Walk the layers in order:

1. The problem exists.
2. The nature of the problem is correct.
3. The direction of the solution is correct.
4. The details of the solution are correct.
5. The solution has no unacceptable side effect.
6. The obstacles are known and handled.
7. The implementation details are correct.

Do not move to a later layer while an earlier layer lacks agreement.
Confirm each agreement with the user before the next layer.
Name the current layer when the user asks about the process.

## Failure Mode

The agent presents solution details before the user agrees on the problem. The user rejects the design.

Sources:

- Efrat Goldratt-Ashlag, "The Layers of Resistance", TOC Handbook, 2010.
- Goldratt, "The Goal", 1984 (the change questions).
