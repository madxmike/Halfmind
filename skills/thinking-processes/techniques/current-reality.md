# Current Reality

## Use When

- The agent collects the problem.
- The user reports symptoms.

## Technique

List each undesirable effect (UDE) as an observable fact.
An observable fact carries a number, a date, or a person.
Connect two UDEs with cause-effect logic: "if X, then Y".
Add the missing steps until the logic holds.
The chain converges on one root cause or one core conflict.
Do not state a solution in this step.

Test each link:

- Read the link as a sentence.
- Ask the user for the reason behind the link.
- Mark the link as an assumption when the reason is unknown.

## Failure Mode

The agent treats a symptom as the root cause. The design fixes a symptom. The symptom returns.

Source: Goldratt, "It's Not Luck", 1994 (current reality tree).
