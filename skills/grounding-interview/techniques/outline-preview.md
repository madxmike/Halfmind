# Outline Preview

## Use When

- The interview is ready for the doc draft.
- The user needs to see the shape before the full text.

## Technique

Present the outline at a rough level: the sections and the headings.
Add the assumptions, the glossary, and the open questions.
Ask for a correction: "Correct the shape before I write the doc."
A shared artifact makes the conversation cheaper. The outline is that artifact.
Write the doc only after the user confirms the outline.

Check:

- The user confirmed the outline, the assumptions, and the glossary.
- The confirmed outline matches the template sections.

## Failure Mode

The agent writes the full doc on an unconfirmed shape.
The user rejects the doc. The agent repeats the work.

Sources:

- Star and Griesemer, 1989 (boundary objects).
- Clark and Brennan, "Grounding in Communication", 1991 (acceptance).
