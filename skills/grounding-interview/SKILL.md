# Grounding Interview

Grounding is the process that adds shared understanding between two people.
The interview grounds the design doc in the user's intent.

The skill folder is `/home/madxmike/workplace/Halfmind/skills/grounding-interview/`.

Read one technique file when its trigger matches the situation.

| Technique | File | Use When |
| --- | --- | --- |
| Read-back | `techniques/read-back.md` | The agent needs user confirmation of its understanding. |
| Question economy | `techniques/question-economy.md` | The agent prepares the next question batch. |
| Concrete examples | `techniques/concrete-examples.md` | An answer is abstract or opinion-based. |
| Root problem | `techniques/root-problem.md` | The user states a solution before a problem. |
| Scope bounding | `techniques/scope-bounding.md` | The interview sets goals, appetite, or exclusions. |
| Assumptions and terms | `techniques/assumptions-and-terms.md` | A term has two meanings or a claim has no proof. |
| Outline preview | `techniques/outline-preview.md` | The interview is ready for the outline confirmation. |

One technique per file. The agent selects a file by trigger.
